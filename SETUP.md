# Self-hosted GitHub stats — setup

This replaces the three badges that were breaking
(`github-readme-stats.vercel.app` for the stats + top-langs cards, and
`github-readme-activity-graph.vercel.app`) with SVGs generated by a
workflow that runs in your own `deepalsr/deepalsr` repo. Nothing here
depends on a shared third-party server, so it can't be rate-limited by
other people's traffic.

## 1. Add the files to your `deepalsr/deepalsr` repo

Copy these into the repo, keeping the paths:

```
scripts/generate_stats.py
.github/workflows/generate-stats.yml
```

## 2. Create a personal access token

1. GitHub → Settings → Developer settings → Personal access tokens →
   Tokens (classic) → Generate new token.
2. Scope: **read:user** is enough (this only reads your own public
   profile data — stars, commits, PRs, issues, languages, contribution
   calendar).
3. Copy the token.

## 3. Add it as a repo secret

In `deepalsr/deepalsr` → Settings → Secrets and variables → Actions →
New repository secret:

- Name: `METRICS_TOKEN`
- Value: the token from step 2

## 4. Run it once

Actions tab → "Generate GitHub Stats" → Run workflow. After it
finishes you'll have:

```
assets/stats/github-stats-dark.svg
assets/stats/top-langs-dark.svg
assets/stats/activity-graph-dark.svg
```

committed to `main`. It also runs automatically every day at 03:00 UTC.

## 5. Point the README at the generated files

Already done in the README included alongside this — the three broken
`<img>` tags now point at:

```
https://raw.githubusercontent.com/deepalsr/deepalsr/main/assets/stats/github-stats-dark.svg
https://raw.githubusercontent.com/deepalsr/deepalsr/main/assets/stats/top-langs-dark.svg
https://raw.githubusercontent.com/deepalsr/deepalsr/main/assets/stats/activity-graph-dark.svg
```

`raw.githubusercontent.com` serves directly from your repo — no
external rendering service in the request path at all.

## Notes / limits

- The streak card (`streak-stats.demolab.com`) wasn't broken in your
  screenshot, so it's left as-is. If it ever breaks too, the same
  pattern (`compute_streaks()` in `generate_stats.py`) already computes
  current/longest streak — it just needs a fourth `render_*` function
  and an `<img>` swap.
- "Total Stars" and the language breakdown only look at your 100
  most-starred owned, non-fork repos (a GraphQL page limit). Fine for a
  profile card; adjust `first: 100` in the query if you ever need more.
- Rank/percentile scoring (the "A+", "S" badges some cards show) isn't
  reproduced — that formula isn't publicly documented, so it's left out
  rather than guessed at.
